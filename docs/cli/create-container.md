# create-container

```
Add a container to the focused workspace by dividing its largest slot

Usage: komorebic.exe create-container [OPTIONS] [AXIS]

Arguments:
  [AXIS]
          Dividing line for the split [default: the longer edge of the largest slot]

          Possible values:
          - left-right: A vertical dividing line producing a left and a right slot
          - top-bottom: A horizontal dividing line producing a top and a bottom slot

Options:
      --count <COUNT>
          How many containers to add
          
          [default: 1]

  -h, --help
          Print help (see a summary with '-h')

```
