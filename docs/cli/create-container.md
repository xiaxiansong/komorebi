# create-container

```
Split a new container off the most recently focused container with windows to spare

Usage: komorebic.exe create-container [AXIS]

Arguments:
  [AXIS]
          Dividing line for the split [default: the donor's longer edge]

          Possible values:
          - left-right: A vertical dividing line producing a left and a right slot
          - top-bottom: A horizontal dividing line producing a top and a bottom slot

Options:
  -h, --help
          Print help (see a summary with '-h')

```
