# move-floating-window

```
Move the focused floating window in the specified direction without touching any container

Usage: komorebic.exe move-floating-window <DIRECTION> [DELTA]

Arguments:
  <DIRECTION>
          [possible values: left, right, up, down]

  [DELTA]
          Distance to move by in logical units, scaled to the monitor's DPI [default: the
          configured floating_move_delta]

Options:
  -h, --help
          Print help

```
