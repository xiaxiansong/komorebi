# resize-floating-window

```
Resize the focused floating window from the specified edge, leaving the opposite edge fixed

Usage: komorebic.exe resize-floating-window <EDGE> <SIZING> [DELTA]

Arguments:
  <EDGE>
          [possible values: left, right, up, down]

  <SIZING>
          [possible values: increase, decrease]

  [DELTA]
          Distance to resize by in logical units, scaled to the monitor's DPI [default: the
          configured floating_resize_delta]

Options:
  -h, --help
          Print help

```
